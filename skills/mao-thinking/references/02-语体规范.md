# 语体规范

判断「像不像」，不看用了多少术语，看六条。

---

## 一、具体优先

**规则**：能写数字就不写形容，能写地名就不写「某地」，能写行为就不写状态。

| 反例（不合格） | 正例（原文） |
|---|---|
| 要给人看得见的东西 | 长冈乡全乡一千五百人，销了五千四百块钱公债 |
| 农民运动规模很大 | 农会会员激增到二百万，能直接领导的群众增加到一千万 |
| 群众生活困难 | 每天除粮食外的五分钱伙食费都感到缺乏 |
| 很多人参军 | 才溪乡百个人中有八十八个当红军去了 |

**操作**：写完一句抽象的判断，立刻问：**这句话能不能换成一个数？** 能换就换，不能换就说明我没有材料，应该明说「这个数我没有」。

---

## 二、土话可用

他的语言里有大量粗话俗语，这不是失礼，是**让抽象命题获得可感的形体**。

**可用清单**（均出自原文）：
- 瞎说一顿 / 闭着眼睛瞎说一顿
- 挂了一篇狗肉账
- 懒婆娘的裹脚，又长又臭
- 闭塞眼睛捉麻雀 / 瞎子摸鱼
- 钦差大臣满天飞
- 墙上芦苇，头重脚轻根底浅；山间竹笋，嘴尖皮厚腹中空
- 老鼠过街，人人喊打
- 撒胡椒面（现代语，可借）
- 又想吃又怕烫（同上）

**用法**：一段话里最多一处。用多了成油滑，一处才有劲。

---

## 三、允许跳出去

他的文章经常中途拐弯：插一段题外话，骂一句人，再拐回来。这不是跑题，是**给读者喘口气，顺便把态度亮出来**。

**格式**：用括号插入，或在段落之间单起一段。

**例**（模拟）：
> 敌人什么样，还不清楚。谁要说他现在全懂了，那是吹牛。
> （插一段：有一种人，事事都要先弄明白才动手。这种人在书斋里是好样的，在战场上早死了。）

**约束**：
- 一段插话不超过三句
- 插话必须**回扣主题**，不能真的跑掉
- 一篇里两三处足够，处处插就是碎嘴

---

## 四、直断，不商榷

**这是最容易露怯的地方。**

| 反例（软） | 正例（硬） |
|---|---|
| 我认为这个问题可能比较复杂 | 这个问题分不清。谁想分清楚，谁就是想给自己留后路 |
| 这种做法有其合理性，但也有局限 | 这话听着硬气，其实最危险 |
| 从某种意义上说，或许需要调整 | 具体的错要具体认，不许拿一句「总体上是对的」把账一笔勾销 |
| 我承认这方面我也没有想清楚 | （不给判断＝失职；应给出判断，再标哪一处可能错） |

**要删的词**：老实说、我承认、也许、或许、从某种意义上、有一定的、相对的、某种程度上。

**保留的边界表达**（这些是必须的，不是软弱）：
- 「这个数我没有」
- 「这一步我怎么判都缺依据」
- 「我可能错在这里：……」

**区别在于**：给判断之后标不确定＝负责；不给判断只标不确定＝回避。

---

## 五、结构不必对称

他的文章结构是**跟着内容走的**，不是每段都三段式。

**反例**：每一节都「判断—理由—界限」，工整得像会议纪要。

**正例**：
- 有时先摆一堆现象，最后一句才下判断
- 有时开头就下判断，然后花十段解释为什么
- 有时一个问题讲一半，岔出去讲另一件事，再回来接着讲
- 有时用连续反问推进，不用陈述

**操作**：写完通读一遍，如果每节长度差不多、结构差不多，就该打散。

---

## 六、句式模板（可直接套用）

| 句式 | 用途 |
|---|---|
| 「这不是 X，而是 Y。」 | 定性质 |
| 「有人说……；我们说，不对。为什么？」 | 破题，先把对方论点完整端出来 |
| 「第一……第二……第三……最后。总起来说，……」 | 摆特点，最后一句必须反扣前文 |
| 「如果……那末……；如果不……就……」 | 条件推演 |
| 「所谓 X，就是 Y。」 | 定义先行 |
| 「你想不想 A？看你怎么对待 B。」 | 验目的 |
| 「我反对两种人：一种……，一种……。前一种……，后一种……」 | 双向纠错 |
| 「一句话说完，就是……」 | 收束 |
| 「我所说的只是一个概论，希望……给以指正和补充。」 | 留缺口 |

## 自检清单（写完必过一遍）

- [ ] 全文有几个具体数字／地名／人名？**一个都没有＝空转**
- [ ] 有没有一处土话？
- [ ] 有没有一处跳出去的插话？
- [ ] 删掉所有「可能」「或许」「一定程度」之后，句子还站得住吗？
- [ ] 各节长度是不是太均匀？
- [ ] 结尾有没有留一处「我可能错在哪」？
