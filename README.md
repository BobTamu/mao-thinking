# mao-thinking

一套可执行的**矛盾分析法**，做成 Agent Skills 格式。用于拆解复杂局势、做战略取舍、写结构硬的分析文章。

它把一套散落在文章里的推理程序，整理成九道可以逐条执行的工序，并且给每一道工序配上自检问句。**核心不是文风，是工序。**

---

## 功能

| # | 功能 | 输入 | 输出 |
|---|---|---|---|
| 1 | **局势研判** | 一个模糊的局势描述 | 定性质（三坐标）＋双方特点（成对）＋主要矛盾（删除测试）＋阶段（可观测判据） |
| 2 | **战略取舍** | 一个「该不该做」的决断 | 条件清单＋阈值＋杠杆条件＋退回方案（含转进判据） |
| 3 | **写硬分析** | 一个题目 | 五段式：提出→分析→综合定性→给办法→写死证伪指标 |
| 4 | **审别人的分析** | 一篇现成的判断 | 逐条标注：哪一句是算出来的，哪一句是宣布出来的 |
| 5 | **越界检查** | 一篇分析 | 标出它在哪一步把局部样本当成了全局结论 |

五类功能共用同一套底层工序，区别只在走到第几步。

### 最有用的一个副产品：**识别「宣布」与「算出」**

任何分析里出现「主要矛盾是 X」，都可以用一句问话验它：

> 解决了 X，其余几条会因什么机制跟着缓和？

答得出机制＝算的；答不出＝宣布的。这一条能筛掉绝大多数看起来漂亮的分析。

### 第 0 步：先声明覆盖度

走九件工具之前，先答一句：**这个题上我实际看过什么、没看过什么、结论适用于哪个范围。**

这一步花不了一分钟，却能挡掉大部分「看起来严谨、其实越界」的分析——没有它，第 3 步（摆特点）和第 4 步（抓主要矛盾）常常会拿一个局部样本推出全局判断，全程看不出破绽。

详见 `references/05-实践与发言权.md`。

## 三层结构

**底层三条公理**（不可跳过）

1. 本质有两把尺——结构尺（主要矛盾）＋功能尺（贯穿一切动作的目的）
2. 条件只提供可能性，结果须方针加努力
3. 真理判据在结果，不在论证

**中层九件工具**（顺序不可乱）

| 序 | 工具 | 一句话 |
|---|---|---|
| 1 | 划界 | 谁受损、谁有力量、谁会先动；**痛感与力量常错位** |
| 2 | 定性质 | 「不是 X 而是 Y」，Y 含时间／双方／赌注 |
| 3 | 摆特点 | 双方各 3–5 条，成对且互相反对，禁合并项 |
| 4 | 抓主要矛盾 | 删除测试：解决它，其余会缓和吗 |
| 5 | 追条件 | 给阈值不给理想态，指出杠杆条件 |
| 6 | 划阶段 | 判据是可观测量，不是日历 |
| 7 | 落办法 | 谁／何时／动作／验收 |
| 8 | 验目的 | 真想还是假想：看怎么对待与 A 相反的 B |
| 9 | 回流 | 提前写死证伪指标 |

**外层五个弹性条款**——每条都自带收紧条件。**抄条款不抄条件，抄到的就是灾难。**

## 它不是什么

- **不是立场表达**。只讲推理结构，不做价值判断。
- **不冒充任何人**。输出必须标明「方法推演」，不得伪造引文或伪托原话。
- **不评价现实议题**。涉及公共议题只给分析框架，结论由使用者自己下。
- **不是万能的**。对纯符号资产的定价、对突变的预测，这套方法明显偏弱；遇到应当直说「这个我看不懂」。
- **不替代事实调查**。这套方法 80% 的重量压在调查上。方法可以复制，调查不能外包；缺数据时必须停下来报缺，而不是往下推。

## 安装

```
~/.workbuddy/skills/mao-thinking/
```

或下载 release 里的 `mao-thinking.zip`，解压到 skills 目录。

目录应为：

```
skills/mao-thinking/
├── SKILL.md                  # 入口：三层结构、语体规范、合规边界
└── references/
    ├── 01-工具详解.md         # 九件工具：原文依据、操作动作、自检问句
    ├── 02-语体规范.md         # 阐述方式六条细则与正反例
    ├── 03-弹性条款.md         # 五个高危条款及其配套条件
    ├── 04-示例.md            # 两个完整走查：个人决策 / 局势研判
    └── 05-实践与发言权.md     # 五个补丁：发言权分级与越界检验
```

## 快速开始

技能装上之后，直接用自然语言触发：

```
按 mao-thinking 拆一下：我们的项目为什么一直卡住
用矛盾分析法看看，这个方案该不该现在动手
这篇分析帮我审一下，哪些结论是宣布出来的
```

预期的输出形状：先给性质判断，再摆双方特点，再做删除测试找主要矛盾，然后给条件与阈值，最后写死一个会让自己难堪的证伪指标。

**中途会停下来要数字。** 这不是推诿——缺关键事实时继续往下推，产出的是形式严谨的空话。
